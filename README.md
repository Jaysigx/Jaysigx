## About me

I'm a **full-stack developer** who likes **end-to-end ownership**: figuring out what to build, writing it, and standing behind it when it’s running for real users. Most of my work is **modern JavaScript/React on the frontend** and **Node + SQL on the backend**—the kind of stack you’d use for dashboards, portals, bookings, integrations, and anything that isn’t well served by a generic page builder.

I’m also comfortable on **FiveM/GTA RP** servers: **Lua**, server performance, and wiring scripts into QB/ESX-style setups without fragile copy-paste glue.

**[Graphinity Lab](https://graphinitylab.com) is basically me**—solo engineer—so there’s **no bait-and-switch** between who sold the job and who debugs prod at midnight. That means I’m picky about clarity: scoped work, sane staging, backups we can point to, and **no pretending a mockup is shipped software**.

Outside the keyboard, I'm motivated by tools that **save people time**, **earn trust under load**, and **still make sense six months later** when someone opens the repo again. If that sounds aligned with how you operate, we're probably a fit. I **ship**; I don't sell pretend software on a slide deck.

### FiveM (GTA RP servers)

FiveM-heavy scripting and tooling also ship through **[Just Development Studios](https://github.com/JustDevelopmentStudio)** — repos, Lua resources, and the ecosystem focus live there · **[justdevelopment.studio](https://justdevelopment.studio/)**

- **Lua scripting** — custom resources and helpers; clean `fxmanifest` setup and dependencies so updates don’t randomly break the server.
- **Performance** — cares about server tick, blocking code, and DB calls that cause lag or hitches with real players online.
- **Database** — MySQL in a way that fits QB / ESX-style servers: sane queries, fewer useless round-trips.
- **Fits the ecosystem** — can work with QB, ESX, and third-party scripts without turning the whole folder into spaghetti.
- **Stable for staff** — aims for changes staff can test, roll back, or debug when something breaks under load—not “it worked on my PC.”

Happy to help with **fixes, new scripts, tuning, or cleanup** on FiveM as well as normal web work.

*Big FiveM jobs: quick look at the server first, then a written plan and quote—same as any serious build.*
